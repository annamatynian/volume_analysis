## Контекст и принцип

**Проблема:** оркестратор сейчас выводит числа и технические метки.
Чтобы сделать аналитический вывод, нужно держать в голове что означает
каждое число. Это барьер для самостоятельного анализа.

**Принцип изменений:** комментарии описывают *что означает число*,
но НЕ делают торговых рекомендаций, НЕ интерпретируют причины и
НЕ говорят куда пойдёт цена.

**Строгий критерий для каждой фразы:**
Задать вопрос: "Это следует из данных напрямую, или это моя интерпретация?"
- "CVD положительный за 4 месяца" — факт ✅
- "покупатели накапливали" — интерпретация ❌
- "цена ниже VAL" — факт ✅
- "институциональные покупатели активизируются" — интерпретация ❌

**Допустимые формулировки:**
- Описание того что измеряет метрика
- Описание направления (положительный/отрицательный/выше/ниже порога)
- Описание того что технически происходит с числами (OI падает при падении цены)
- Шкала значений с границами без оценки ("исторически зона дна" — только
  если это прямая ссылка на задокументированный факт, не вывод)

### Блок 1: POC Quality Score

**Сейчас:**
```
💯  POC Quality: 0.712 → FAIR_VALUE_MAGNET
    Flags: BULLISH_DIVERGENCE_ACCUMULATION
```

**Стать должно:**
```
[POC QUALITY SCORE]
──────────────────────────────────────────────────────────────────
💯  Итоговый скор: 0.712 → FAIR_VALUE_MAGNET

    Что означает метка:
      FAIR_VALUE_MAGNET  (score > 0.65): совокупность компонентов
        указывает на высокую концентрацию торгового интереса у POC.
      NEUTRAL            (0.35–0.65):    компоненты не дают однозначной картины.
      RESISTANCE_TRAP    (score < 0.35): совокупность компонентов
        указывает на низкую поддержку уровня данными.

    Из чего сложился скор (веса фиксированы):
      • Поглощение (40%): X дней с признаками поглощения из Y дней у POC.
        Доля = X/Y. Поглощение = высокий объём + закрытие в верхних 30%
        диапазона свечи + нисходящий контекст (все три условия одновременно).

      • On-chain (35%):  Z-score = N.NN относительно STH realized price.
        Капитуляция LTH = True/False (порог: убыток >$300M/день × 3 дня подряд).
        При капитуляции = True компонент получает максимальное значение 1.0.
        При капитуляции = False компонент = sigmoid(z_score).

      • Объём (25%):     W-Score = NN.N% — доля объёма POC от максимального
        объёма среди всех проанализированных уровней (POC, VAH, VAL, кластер).
        100% = POC проторгован сильнее всех остальных уровней.

      • OI-коррекция (±0.10, после взвешивания):
        LIQUIDATION  → +0.10 к score
        STRONG_BEAR  → −0.10 к score
        Остальные режимы → без изменений.

    Флаги:
      BULLISH_DIVERGENCE_ACCUMULATION:
        условие — капитуляция = True И доля поглощения > 0.3.
        Оба условия выполнены одновременно.
      LTH_CAPITULATION_ZONE (если есть):
        условие — LTH Proxy SOPR < 0.60.
```

**Реализация:** в блоке 8 оркестратора после `print(poc_quality['score'])`
добавить f-string блок с разбивкой по компонентам. Все данные уже доступны
в переменных (`absorption_near_poc`, `total_near_poc`, `z_score_val`,
`capitulation`, `volume_w_score_poc`, OI-режим).

### Блок 2: Delta Context Score

**Сейчас:**
```
[DELTA CONTEXT] anchor_months=[(2025, 1), (2025, 2)] | avg_cvd_slope=1243.5 | poc_bin_delta=8920.3 | delta_context_score=0.634
```

**Стать должно:**
```
[DELTA CONTEXT]
──────────────────────────────────────────────────────────────────
Anchor period (~4 мес, aggTrades): avg_cvd_slope = +1243.5
  Месяцы анализа: янв 2025, фев 2025.
  CVD slope — наклон кумулятивной дельты (buy_vol − sell_vol) за период.
  Положительный: суммарно buy_vol превышал sell_vol на уровне POC.
  Отрицательный: суммарно sell_vol превышал buy_vol на уровне POC.

Reaction period (14 дней, klines 1m): poc_bin_delta = +8920.3 BTC
  Суммарная дельта (taker_buy − taker_sell) в бине POC за 14 дней.
  Положительная: taker_buy_vol суммарно больше taker_sell_vol.
  Отрицательная: taker_sell_vol суммарно больше taker_buy_vol.

Итоговый delta_context_score = 0.634
  Формула: sigmoid(0.6 × tanh(slope/1000) + 0.4 × tanh(delta/500))
  Диапазон [0.0–1.0], симметричен вокруг 0.5.
  > 0.5: оба или один из сигналов положительны, взвешенная сумма > 0.
  < 0.5: оба или один из сигналов отрицательны, взвешенная сумма < 0.
  = 0.5: сигналы компенсируют друг друга или оба равны нулю.
  Влияние на скор: если > 0.65 → absorption_score += 0.10 перед расчётом.
                   если < 0.35 при volume_score > 0.6 → label = RESISTANCE_TRAP.
```

**Реализация:** заменить одну строку `print(f"[DELTA CONTEXT]...")` на
многострочный блок с условными ветками через if/else для знака slope и delta.

### Блок 3: OI Regime

**Сейчас:** OI режим нигде не выводится отдельным блоком.

**Стать должно — добавить отдельный блок после `[ABSORPTION DETECTION]`:**
```
[OI REGIME — последний день]
──────────────────────────────────────────────────────────────────
Режим: LIQUIDATION
Данные: цена −3.2% | OI −4.1%

Что измеряет режим: соотношение направления цены и изменения
открытого интереса (суммарный объём незакрытых позиций).

Матрица режимов (порог ±1%):
  STRONG_BULL : цена↑ > 1%  И  OI↑ > 1%  — цена растёт, OI растёт
  WEAK_BULL   : цена↑ > 1%  И  OI↓ < 1%  — цена растёт, OI падает
  STRONG_BEAR : цена↓ < −1% И  OI↑ > 1%  — цена падает, OI растёт
  LIQUIDATION : цена↓ < −1% И  OI↓ < 1%  — цена падает, OI падает
  NEUTRAL     : изменения в пределах ±1% по любому из параметров

► Текущий режим: LIQUIDATION — цена падает, открытый интерес падает.
```

**Реализация:** новый print-блок после absorption detection, используя
`df['oi_regime'].iloc[-1]`, `df['price_change_pct'].iloc[-1]`,
`df['oi_change_pct'].iloc[-1]`. Строка "► Текущий режим" подставляется
динамически через f-string.

### Блок 4: Капитуляция (On-chain)

**Сейчас:** `_loss_df` загружается но не выводится. Капитуляция
отражается только как True/False в скоринге.

**Стать должно — добавить в блок `[PROGNOSTIC STRESS-TEST]`:**
```
[ON-CHAIN: LTH REALIZED LOSS]
──────────────────────────────────────────────────────────────────
Реализованный убыток LTH за последние 3 дня (порог $300M):
  DD.MM.YYYY: $XXX.X млн  [████████░░]  [выше / ниже порога]
  DD.MM.YYYY: $XXX.X млн  [█████░░░░░]  [выше / ниже порога]
  DD.MM.YYYY: $XXX.X млн  [███░░░░░░░]  [выше / ниже порога]

Сигнал капитуляции (все 3 дня > $300M): ДА / НЕТ

Что измеряет метрика: объём USD, реализованный LTH-когортой
(монеты >155 дней) в убыток за день. Порог $300M — параметр
функции check_capitulation_signal(), не абсолютный стандарт.

STH Realized Price: $XX,XXX
Z-score текущей цены относительно STH Realized Price: N.NN
  Формула: (current_price − mean(STH_RP)) / std(STH_RP) за 365 дней.
  > 0: текущая цена выше среднего STH realized price за год.
  < 0: текущая цена ниже среднего STH realized price за год.
  Абсолютные границы шкалы: −3 ... 0 ... +3 (типичный диапазон).
```

**Реализация:** использовать `_loss_df` (уже загружен в оркестраторе).
Прогресс-бар `[████░░░░░░]` считать как `int(value / 300M * 10)` блоков.
