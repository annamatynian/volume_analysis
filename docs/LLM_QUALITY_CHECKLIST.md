## ЧАСТЬ 1 — ОБЯЗАТЕЛЬНЫЕ ТРЕБОВАНИЯ К ЛЮБОМУ ВЫВОДУ

### 1.1 Формат вывода

- [ ] Текст заканчивается **точкой**, не обрывается на полуслове
- [ ] Количество абзацев: **не менее 3** (меньше = обрыв или недостаточно метрик)
- [ ] Язык: **русский** в соответствии с промптом
- [ ] Идентификаторы метрик (например, "LTH SOPR", "ETF Flow") написаны **правильно** (не переименованы)

### 1.2 Запрещённый язык

**Запрещено** (хотя бы одно попадание = валидация провалена):

| Категория | Примеры запрещённых формулировок |
|---|---|
| Рекомендации | "купите", "продавайте", "рекомендую открыть", "следует войти" |
| Прогнозы цены | "цена вырастет", "будет расти", "упадёт до", "достигнет" |
| Причинность о будущем | "что приведёт к росту", "поэтому цена", "обусловит рост" |
| Инвестиционные советы | "хорошая возможность для покупки", "зона накопления подходит" |

**Разрешено** (правильные формулировки):

| Формулировка | Пример |
|---|---|
| Описание сигнала | "LTH SOPR ниже 1.0, что указывает на реализацию убытков" |
| Определение зоны | "метрика находится в зоне EARLY_2018_RANGE" |
| Цитата паттерна | "по методологии Mozart является рубиконом безубытка" |
| Исторический контекст | "аналогичные значения наблюдались в 2018 и 2022" |

## ЧАСТЬ 2 — КОНТРАРИАНСКИЕ СИГНАЛЫ (КРИТИЧЕСКИ ВАЖНО)

Контрарианские сигналы — самое опасное место: любой из них может быть ошибочно
описан LLM без учёта инвертированной полярности.

### 2.1 Н-01 | RSI < 20 — Контрарианский (OVERSOLD → BULLISH)

**Паттерн Mozart** (пост 05.02.2026):
Дневной RSI < 15 = исторически редкий уровень. Единственный прецедент — коронадамп 2020.
Перепроданность = повышенная вероятность разворота — это BULLISH (Mozart).

| Сценарий | Как должна описывать LLM | Полярность |
|---|---|---|
| RSI = 15 (активный) | RSI в зоне экстремальной перепроданности, единственный прецедент 2020 | BULLISH |
| RSI = 55 (нейтральный) | RSI в нейтральной зоне, не достигает перепроданности | NEUTRAL |

**Ошибка LLM:** если RSI < 20 и LLM пишет "медвежий сигнал" вместо "контрарианский бычий" — ошибка.

- [ ] Проверено: LLM описывает Н-01 как **бычий** (а не медвежий) сигнал при OVERSOLD/EXTREME_OVERSOLD
- [ ] Проверено: если сигнал NEUTRAL — LLM не называет его ни бычьим, ни медвежьим

---

### 2.2 Н-02 | Красные месяцы подряд — Контрарианский (N ≥ 4 → BULLISH)

**Паттерн Mozart** (пост 11.02.2026):
5 красных месяцев подряд = единственный исторический прецедент (авг–дек 2018 = завершение медвежки).
Важная оговорка Mozart: сигнал = перепроданность по месячному ТФ, не гарантия окончания медвежки.

**Ошибка LLM:** описать серию красных свечей только как "продолжение снижения" без упоминания
контрарианской природы сигнала.

- [ ] Проверено: LLM называет сигнал **контрарианским** (статистическая редкость = бычий)
- [ ] Проверено: LLM упоминает **оговорку Mozart**: не гарантия окончания медвежки

---

### 2.3 М-05 | LTH NUPL EUPHORIA — Контрарианский (> 0.75 → BEARISH)

**Паттерн Mozart** (пост 05.04.2026):
LTH NUPL > 0.75 = эйфория LTH → риск распределения → BEARISH (контрарианский).
LTH NUPL от 0 до 0.75 = прибыль LTH без эйфории → BULLISH (прямой сигнал).

**Текущее (2026-05-25):** LTH NUPL = 0.38 → зона HOPE → BULLISH (не контрарианский).

**Ошибка LLM:** называть LTH NUPL = 0.38 "опасным" или "риском" без объяснения
что порог эйфории — 0.75, и текущее значение его не достигает.

- [ ] Проверено: LLM корректно различает 2 случая: NUPL < 0.75 (BULLISH) vs NUPL > 0.75 (BEARISH)
- [ ] Проверено: LLM не путает "LTH в прибыли" (факт) с "риском распределения" (только при > 0.75)

---

### 2.4 М-10 | LTH Realized Loss EXTREME — Контрарианский (> $500M → BULLISH)

**Паттерн Mozart** (пост 02.04.2026):
Пик убытков > $500M/день = исчерпание продавцов = разворотный сигнал по методологии Mozart.
Исторические якоря: $140M (2018), $300M, $480M (FTX). Текущий цикл — ожидаемый порог > $500M.

**Текущее (2026-05-25):** 7d MA = $213.7M → зона EARLY_2018_RANGE → BEARISH (ещё не контрарианский).

**Ошибка LLM:** называть $213M/день "экстремальным" или путать с порогом $500M.

- [ ] Проверено: LLM различает зоны EARLY_2018 (BEARISH) vs EXTREME > $500M (BULLISH-контрар.)
- [ ] Проверено: LLM упоминает исторические якоря: $140M (2018), $480M (FTX), цель > $500M
- [ ] Проверено: LLM не называет $213M "экстремальным" — до EXTREME ещё > $286M

## ЧАСТЬ 3 — ТОЧНОСТЬ ЗНАЧЕНИЙ МЕТРИК (защита от галлюцинаций)

LLM имеет доступ к числовым значениям через `raw_metrics`. Галлюцинация = LLM
выдумывает значения которых нет в промпте. Проверяется по выводу оркестратора.

Читать лог последнего запуска и сверять числа в LLM-тексте с блоками оркестратора:

| Метрика | Значение в оркестраторе | Значение в LLM-тексте | Совпадает? |
|---|---|---|---|
| LTH SOPR | (HOLDER STRUCTURE) | | ☐ |
| STH SOPR | (HOLDER STRUCTURE) | | ☐ |
| LTH MVRV | (HOLDER STRUCTURE) | | ☐ |
| STH MVRV | (HOLDER STRUCTURE) | | ☐ |
| LTH NUPL | (HOLDER STRUCTURE) | | ☐ |
| STH NUPL | (HOLDER STRUCTURE) | | ☐ |
| LTH Net Pos 30d | (HOLDER STRUCTURE) | | ☐ |
| STH Net Pos 30d | (HOLDER STRUCTURE) | | ☐ |
| ETF Flow | (EXCHANGE FLOWS) | | ☐ |
| LTH Realized Loss 7d MA | (LTH REALIZED LOSS) | | ☐ |
| Supply in Loss | (МБ-04) | | ☐ |
| NUPL | (МБ-06) | | ☐ |
| MVRV Z-Score | (МБ-07) | | ☐ |
| RSI | (Signal Alignment) | | ☐ |
| VWAP Deviation | (FINAL VERDICT) | | ☐ |

**Правило:** любое число, упомянутое LLM без округления — должно совпадать
с числом в оркестраторе до двух значимых цифр. Расхождение > 10% = галлюцинация.

## ЧАСТЬ 4 — СООТВЕТСТВИЕ ЗОНАМ MOZART

Проверяем только **активные сигналы** (из блока [SIGNAL ALIGNMENT]).

### М-01 | LTH SOPR

| Зона | Размер убытка | Фаза по Mozart | Что должна сказать LLM |
|---|---|---|---|
| > 1.0 | прибыль | Бычий / распределение | LTH продают выше себестоимости |
| = 1.0 | рубикон | рубикон безубытка | граница (пробой 6 февраля 2026) |
| 0.80–1.00 | 0–20% | Ранняя медвежка | LTH продают средний убыток 0–20% |
| < 0.80 | 20–50% | Разгар медвежки | кульминация нарастает (цель 40–50%) |

**Текущее (2026-05-25):** SOPR = 0.91 → ранняя медвежка

- [ ] LLM называет зону: ранняя медвежка / рубикон пройден (не "капитуляция")
- [ ] LLM не путает 0.91 с капитуляцией — по Mozart капитуляция: SOPR < 0.50–0.80

### М-02 | STH SOPR

**Текущее (2026-05-25):** STH SOPR = 1.00 (нейтральная зона, RUBICON)

- [ ] LLM называет: зона давления продаж при отскоке / нейтральная зона STH
- [ ] LLM упоминает двойственность уровня 1.0: поддержка (бычий) vs сопротивление (медвежий)

### М-03+04 | LTH MVRV / STH MVRV

**Текущее (2026-05-25):** LTH MVRV = 1.61, STH MVRV = 0.99

- [ ] LLM: LTH MVRV > 1.0 → потенциальное давление распределения (не "бычий рынок")
- [ ] LLM: STH MVRV ≈ 1.0 → STH у безубытка, нейтральная зона сопротивления

### М-06 | STH NUPL

**Текущее (2026-05-25):** STH NUPL = -0.01 (капитуляция STH, BEARISH)

- [ ] LLM: STH NUPL < 0 → капитуляция краткосрочников
- [ ] LLM не путает STH NUPL с LTH NUPL — это разные метрики

### М-07+08 | Cohort Flow

**Текущее (2026-05-25):** LTH Net+ = +1.1M, STH Net− = -1.06M (ACCUMULATION)

- [ ] LLM называет направление перетока: STH → LTH = накопление
- [ ] LLM не путает "накопление" с "ростом цены" — это разные процессы

### М-10 | LTH Realized Loss

**Текущее (2026-05-25):** 7d MA = $213.7M (зона EARLY_2018_RANGE, 44.5% от FTX пика)

- [ ] LLM упоминает исторические якоря: $140M (2018), $300M, $480M (FTX), цель > $500M
- [ ] LLM не называет $213M "экстремальным" — до EXTREME ещё далеко

### М-11 | ETF Flow

**Текущее (2026-05-25):** -1300.3 BTC (OUTFLOW, BEARISH)

- [ ] LLM: оттоки ETF = нет нового покупателя, рост затруднён (формулировка Mozart)
- [ ] LLM не называет -1300 BTC "незначительным" без исторического контекста

### М-12 | HODL Waves MTH

**Текущее (2026-05-25):** 1m_3m = 1.08M, 3m_6m = 2.64M, 6m_1y = 2.80M

- [ ] LLM интерпретирует соотношение когорт: 3m_6m >> 1m_3m = монеты стареют = накопление
- [ ] LLM не путает HODL Waves с размером позиции — здесь динамика перехода между корзинами
