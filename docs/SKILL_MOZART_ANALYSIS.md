## СИГНАЛЫ И ИХ ПЕРВОИСТОЧНИКИ

### М-01 | LTH SOPR
**Источник:** пост 05.04.2026
**Рубикон:** 1.0 — граница между ранней медвежкой и разгаром
**Фазы:** > 1.0 бычий / 0.80–1.00 ранняя медвежка / 0.50–0.80 разгар / < 0.50 кульминация (целевой диапазон 40–50% убытка)
**Сигнал дна:** SOPR перестаёт падать и начинает расти при стоячей цене — не значение, а смена производной
**Важно:** после кульминации следует 6–12 месяцев боковика («фаза равновесия») — лучшее окно для долгосрочного лонга

### М-02 | STH SOPR
**Источник:** пост 16.04.2026
**Рубикон:** 1.0 — нейтральная зона
**Правило:** в медвежьем рынке STH SOPR ≈ 1.0 = сопротивление; в бычьем = поддержка

### М-03 | LTH MVRV
**Источник:** пост 25.02.2026, 14.01.2026
**Бинарный сигнал:** > 1.0 = LTH в прибыли (потенциальное давление продаж); < 1.0 = LTH в убытке (давление снижено)
**Важно:** Mozart не называет конкретных числовых порогов выше 1.0 — использует как качественный сигнал

### М-04 | STH MVRV
**Источник:** пост 16.04.2026
**Правило:** STH MVRV ≈ 1.0 = нейтральная зона сопротивления в медвежьем рынке
**Важно:** Конкретные числовые пороги Mozart не называет — оперирует через % прибыльных кошельков

### М-05 | LTH NUPL (контрарианский сигнал)
**Источник:** пост 05.04.2026, 15.05.2026
**Контрарианский:** EUPHORIA (> 0.75) → BEARISH в alignment (риск распределения)
**Рубикон:** 0 = переход в медвежий рынок

### М-06 | STH NUPL (контрарианский сигнал)
**Источник:** пост 16.04.2026
**Контрарианский:** EUPHORIA → BEARISH в alignment
**Правило:** STH NUPL < 0 = капитуляция STH; ≈ 0 = максимальное потенциальное давление продаж

### М-07+08 | Cohort Flow (LTH/STH Net Position 30d)
**Источник:** пост 14.01.2026
**Правило:**
- LTH Net+ / STH Net− = накопление: STH передают монеты LTH → бычий фон
- LTH Net− / STH Net+ = распределение: LTH передают монеты STH → медвежий фон
**Исторический якорь:** LTH Net на многолетнем минимуме продаж → исторически предшествует развороту

### М-09 | STH RP Z-score (паттерн В)
**Источник:** пост 25.02.2026
**Правило:** STH RP — главное сопротивление при отскоке снизу-вверх в медвежьем рынке
**Динамика:** линия снижается со временем (STH обновляются — старые покупатели становятся LTH)
**Паттерн В:** Z-score разворачивается вверх при стоячей цене → сигнал дна формируется
**Усиление уровня:** при совпадении STH RP и One-Cycle Average (МБ-08) — уровень двойной природы

### М-10 | LTH Realized Loss (контрарианский)
**Источник:** пост 02.04.2026, 03.04.2026
**Контрарианский:** EXTREME / EXTREME_OVERSOLD → BULLISH в alignment (истощение продавцов)
**Исторические якоря:** 2018 пик ~$140M/день; 2022 волна 1 ~$300M; 2022 FTX пик ~$480M; текущий цикл ожидание >$500M
**Важно:** часть убытков — принудительные продажи майнеров (Marathon продала 15k BTC в апреле 2026), что завышает сигнал
**Затухание:** каждый цикл пиковые убытки в % от рынка меньше предыдущего

### М-11 | ETF Flow
**Источник:** пост 08.04.2026
**Правило:** устойчивые оттоки = нет нового институционального покупателя = рост затруднён
**Двойное подтверждение:** возобновление притоков + Supply in Loss < 5M = сигнал смены тренда

### М-12 | HODL Waves MTH когорта
**Источник:** пост 13.05.2026 (контекст)
**Правило:**
- age_1m_3m падает + age_3m_6m растёт = монеты стареют = накопление
- age_1m_3m растёт + age_3m_6m падает = распределение старых позиций
**Важно:** Mozart не называет числовых порогов — качественный анализ направления

### М-15 | Funding Rate 30d MA
**Источник:** пост 11.03.2026
**Правило:** 30-дневная MA funding rate на многолетнем минимуме (с начала 2023) = исторически предшествует локальному дну
**Зона FLOOR_ZONE:** MA ≤ −0.0050 — паттерн Mozart активен
**Порог:** из `MOZART_CONFIG['funding_rate_ma_floor']`

### МБ-01 | Realized Price — «Синяя линия»
**Источник:** пост 25.02.2026
**Правило:** исторически совпадает с зоной дна циклов 2015, 2018, 2020
**Зона AT:** ±20% от Realized Price — историческая зона дна цикла
**Иерархия:** самый сильный уровень из трёхлинейной модели Mozart (Синий > Красный > Зелёный)
**Порог буфера:** из `MOZART_CONFIG['realized_price_buffer_pct']`

### МБ-02 | True Market Mean — «Зелёная линия»
**Источник:** пост 25.02.2026
**Рубикон:** цена ниже TMM = медвежий рынок подтверждён; Mozart: «пробой вниз на объёме — смена глобального тренда»
**Совместно с STH RP:** зона $TMM–$STH_RP = основная зона сопротивления при отскоке

### МБ-03 | STH Profit
**Статус:** ВСЕГДА missing (н/д) — endpoint не существует на free tier BGeometrics
**Источник паттерна:** пост 16.04.2026, пост 09.09.2025
**Пороги по Mozart:** нейтральная зона 51–59%, heated 69–76%, over-heated 85–95%
**Данные недоступны** — аппроксимация через utxos-in-profit-pct неточна (включает LTH)

### МБ-04 | Supply in Loss
**Источник:** пост 02.04.2026, пост 08.04.2026
**Ключевой порог:** снижение до 5M BTC = структурный сигнал смены тренда (подтверждено 2019, 2022)
**Промежуточный порог:** 3–3.5M = «активное» давление непосредственно над ценой
**Расчёт:** снижение с ~9M до 5M исторически = рост от дна на 60–90%
**Пороги:** из `MOZART_CONFIG['supply_loss_structural_trigger']` и `supply_loss_intermediate_trigger`

### МБ-05 | LTH Realized Profit (в разработке)
**Источник:** пост 14.01.2026
**Порог:** 7-дн MA > $1B/день = медвежий риск давления распределения
**Исторический пик:** конец ноября 2025 ~$2B/день = «капитуляция в остаточном профите»

### МБ-06 | NUPL
**Источник:** пост 15.05.2026
**Зоны:** BULL ≥ 0.50 / HOPE 0.25–0.50 / EARLY_BEAR 0.0–0.25 / BEAR −0.40–0.0 / BOTTOM_ZONE ≤ −0.40
**Цель дна текущего цикла:** ~−0.40 (по Mozart, с поправкой на затухание сигнала каждый цикл)
**Пороги:** из `MOZART_CONFIG`

### МБ-07 | MVRV Z-Score
**Источник:** пост 25.02.2026 (контекстуально)
**Зоны:** PEAK > 7 / BULL 3–7 / NEUTRAL 0–3 / BEAR −1–0 / BOTTOM ≤ −1
**Важно:** Mozart не называет MVRV Z-Score явно, использует логику market cap vs realized cap через другие метрики
**Пороги:** из `MOZART_CONFIG`

### МБ-08 | One-Cycle Average
**Источник:** пост 13.05.2026
**Рубикон:** цена ниже OCA = техническая медвежка; > 60 дней ниже = подтверждённая медвежка
**Формула дна:** OCA × 0.50 = минимальная цель; OCA × 0.45 = максимальная глубина
**Временная регрессия:** медвежка длится 9–17 месяцев (медиана ~12–13 месяцев)
**Два условия Mozart:** (1) нет форс-мажора, (2) цена ниже OCA > 2 месяцев
**Порог:** из `MOZART_CONFIG['one_cycle_days_threshold']`

### Н-01 | RSI(14)
**Источник:** пост 05.02.2026
**Экстремальная зона:** RSI < 15 — исторически единственный прецедент до 2026: коронадамп 2020
**Правило:** не самостоятельный сигнал — подтверждение к on-chain сигналам
**Пороги:** из `MOZART_CONFIG`

### Н-02 | Красные месячные свечи
**Источник:** пост 11.02.2026
**Правило:** N ≥ 5 = единственный исторический прецедент BTC (август–декабрь 2018 = завершающая стадия медвежки)
**Важная оговорка Mozart:** N = 5 в начале медвежки ≠ конец медвежки; указывает на перепроданность по месячному ТФ
**Пороги:** из `MOZART_CONFIG`

### НВ-01 | Регрессия убывающих пиков
**Источник:** пост 31.03.2026
**Паттерн:** $87k → $84k → $76k → проекция $63–67k (линейная регрессия по swing highs)
**Режимы:** DESCENDING_STRONG (монотонно) / DESCENDING_WEAK (с нарушениями) / FLAT / ASCENDING
**Применение:** каждый новый пик в зоне регрессии = зона для шорта по Mozart

### НВ-02 | PPI → CPI макро-фильтр
**Источник:** пост 13.05.2026
**Правило:** PPI > 1% за месяц = опережающий сигнал роста CPI через 1–3 месяца → ФРС удерживает ставку → ликвидность ограничена
**Важно:** макро-контекст, не торговый сигнал; снижает интерпретируемую силу сигналов разворота

### НВ-03 | BTC Dominance (ротация)
**Источник:** пост 10.05.2026
**Паттерн ротации:** micro-cap (2–4 недели опережения) → mid-cap (SOL/LINK/ADA) → large-cap (ETH/BTC)
**Прокси:** снижение BTC.D > 2% за скользящий месяц = начало rotation в альты
**Порог:** из `MOZART_CONFIG['btc_dominance_rotation_threshold_pct']`

## SIGNAL ALIGNMENT — КАК ЧИТАТЬ

**Счёт:** каждый BULLISH сигнал +1, каждый BEARISH −1, NEUTRAL 0, Н/Д не считается
**Вердикт:** ≥ +2 → BULLISH; ≤ −2 → BEARISH; между → MIXED/NEUTRAL
**Контрарианские (*):** М-05, М-06, М-10, Н-02 — полярность инвертирована
  - М-10 EXTREME → BULLISH (истощение продавцов, не усиление медвежки)
  - М-05 EUPHORIA → BEARISH (риск распределения)
**Н/Д:** API недоступен или данных недостаточно — не влияет на счёт

## ОБЩИЕ ПРИНЦИПЫ MOZART

**Затухание сигнала** (посты 05.04.2026, 15.05.2026, 02.04.2026):
каждый цикл пиковые значения метрик в % от рынка меньше предыдущего на ~15–20%.
Исторические пороги применять со скидкой.

**Схождение уровней** (пост 11.02.2026):
зона считается сильной если к ней приходят 3+ независимых уровня из разных методологий.

**Два условия медвежьего рынка** (пост 13.05.2026):
(1) нет форс-мажора, (2) цена ниже One-Cycle Average более 2 месяцев.

**Три сценария с вероятностями** (пост 16.02.2026):
Mozart всегда строит три сценария. Один наиболее вероятный (60–70%), два альтернативных.
